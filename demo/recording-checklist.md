# Recording Checklist

## Before recording

- [ ] Read docs/walkthrough.md and personally trace one site and circle event.
- [ ] Run install.bat and test.bat yourself; review the actual output.
- [ ] Run the batch command in script.md and inspect PNG, CSV and JSON.
- [ ] Try click insertion, Compute and Export yourself.
- [ ] Close unrelated windows and notifications; do not expose credentials.
- [ ] Open the architecture, source excerpts and scaling plot in advance.
- [ ] Set recorder to capture the application/terminal at readable resolution.
- [ ] Test microphone volume and make a short playback check.
- [ ] Rehearse with a timer; aim for 4:45 and keep below five minutes.

## Required content

- [ ] State GPT-6.1 assistance and actual plan accurately.
- [ ] Show both batch and interactive input.
- [ ] Show image and machine-readable exports and statistics.
- [ ] Explain the beach-line and event-queue invariants.
- [ ] Discuss three actual decisions/problems from the implementation.
- [ ] Show test results, real benchmarks and a numerical limitation.
- [ ] Narrate personally; answer questions in your own words.

## After recording

- [ ] Play the entire video; check sound, duration and readable text.
- [ ] Save as demo/walkthrough.mp4 in the repository, or
  04_Demo/walkthrough.mp4 in the package. Do not publish a large video to Git
  accidentally; it is excluded from Git and should be included in the ZIP.
- [ ] Supply two real AI screenshots as evidence/ai-interaction-1.png and
  evidence/ai-interaction-2.png, showing both substantive prompt and response.
- [ ] Record screenshot dates/context and actual subscription plan in docs/evidence.md.
- [ ] Rebuild the package after adding evidence; inspect its completeness manifest.
